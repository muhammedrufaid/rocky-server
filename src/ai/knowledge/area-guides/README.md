# Area Guides

## Purpose

Stores helpful summaries of Dubai communities and areas — lifestyle overview, typical property mix, and high-level orientation for buyers and renters.

## Example questions

- Tell me about Dubai Marina.
- What is Dubai Hills like?
- Is Business Bay good for investment? *(answer carefully — no guarantees)*
- Which areas are popular for families?
- Tell me about JLT.

## Future data source

- CMS / Area Guide module (Rocky already has area guide APIs/content in the product)
- Markdown area summaries
- Editorial / marketing area pages
- Database sync from existing `AreaGuide` content

## Notes

- Primarily static curated content; refresh periodically.
- Never invent schools, hospitals, metro stations, ROI, or developer details.
- If a detail is missing, say so.
- Live listing counts and prices for an area come from **property tools**, not this folder.
