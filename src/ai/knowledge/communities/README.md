# Communities

## Purpose

Stores community-level overviews that complement area guides — neighbourhood character, who typically lives there, and property typologies at a summary level.

## Example questions

- What is Arabian Ranches like as a community?
- Tell me about living in Palm Jumeirah.
- Is Downtown more apartments or villas?
- Which communities suit investors vs end-users? *(no guarantees)*

## Future data source

- CMS
- Markdown community profiles
- Area guide cross-links (`area-guides/`)
- Editorial database

## Notes

- Static knowledge; closely related to `area-guides/` — prefer one canonical source per community when content is added to avoid duplication.
- Never invent amenities, schools, or ROI figures.
- Live inventory for a community is dynamic (tools).
