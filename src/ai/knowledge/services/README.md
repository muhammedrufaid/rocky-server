# Services

## Purpose

This folder stores information about **Rocky Real Estate services**.

Each subfolder covers one service domain so content stays focused and easy to retrieve later (RAG / tools).

## Subfolders

| Folder | Domain |
|--------|--------|
| `buying/` | Helping clients buy property |
| `selling/` | Helping clients sell property |
| `renting/` | Helping clients rent property |
| `mortgage/` | Mortgage assistance (general, non-advisory) |
| `property-management/` | Property management services |
| `inspection/` | Property inspection |
| `brokerage/` | Brokerage services |
| `after-sales/` | After-sales support |

## Example questions

- What property management services do you offer?
- Tell me about brokerage.
- How does after-sales support work?
- Can Rocky help me sell my apartment?
- Do you assist with mortgages?
