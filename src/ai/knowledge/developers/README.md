# Developers

## Purpose

Stores verified, high-level information about property developers relevant to Rocky’s market conversations (e.g. known brands clients ask about).

## Example questions

- Who is Emaar?
- Tell me about Damac.
- Which developers build in Dubai Hills?
- Is this developer reputable?

## Future data source

- CMS / Admin Panel
- Markdown developer profiles
- Curated research notes
- Database of developer metadata

## Notes

- Static curated facts only.
- Do not invent track record, awards, financial health, or completion guarantees.
- Project-specific completion dates and payment plans are dynamic — use tools / live sources when available.
- If unknown, say information is unavailable.
