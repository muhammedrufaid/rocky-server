# Blogs

## Purpose

Stores educational and editorial content that helps visitors understand Dubai real estate topics — buying/renting process, freehold concepts, investor visa overviews, market education, and similar guides.

## Example questions

- How does the buying process work in Dubai?
- What is freehold vs leasehold?
- Tell me about the investor visa.
- What should first-time buyers know?
- How does renting work in Dubai?

## Future data source

- CMS / Blog platform
- Website blog sync
- Markdown articles in this folder
- Editorial database

## Notes

- Static / periodically updated content.
- Never make legal promises or give financial advice.
- When RAG is added, blogs are good candidates for chunking because articles are longer-form.
- Prefer retrieving from approved content over model improvisation.
